# LAB4_PES1UG24AM334

Pac-Man style maze game built with Pygame.

## Prerequisites

Install [uv](https://docs.astral.sh/uv/) if you do not already have it:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

## Setup

From this directory, add the game dependency and sync the environment:

```bash
uv add pygame
uv sync
```

## Run

```bash
uv run final_game.py
```

Use the arrow keys to move. Close the window or press Esc to quit.
