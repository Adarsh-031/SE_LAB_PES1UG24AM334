# Known Issue Review

Reviewed `pylint_report_before.txt`, `flake8_report_before.txt`, and `bandit_report_before.txt` against `electricity_bill.py`. All line numbers below refer to that source file. The reports contain 26 Pylint diagnostics (score: 5.44/10), 4 Flake8 diagnostics, and 4 Bandit diagnostics. Repeated diagnostics are grouped into 14 issue categories.

No separate handout or common-issues list is present in the repository. The cross-reference therefore uses the tools' reported rule IDs and official documentation linked below. Bandit severity and confidence are preserved; Pylint warning/convention categories and Flake8 style findings are not assigned invented severity levels.

| Issue | Type | Line(s) | Description | Fix Approach |
|-------|------|---------|-------------|--------------|
| Shell command injection | Security — Bandit B605; High severity, High confidence | 63 | `os.system()` concatenates `meterIp` into a shell command. A caller-controlled value can introduce shell syntax and execute additional commands. The helper is not called by the demo, but remains unsafe when invoked. | Replace the shell command with an HTTP client request; validate the meter host, set a timeout, and handle request failures. If retaining curl, use `subprocess.run()` with a list of arguments and `shell=False`, plus host validation. |
| Unsafe XML parsing call | Security — Bandit B314; Medium severity, High confidence | 18 | `ET.fromstring(xmlText)` matches the unsafe XML parsing rule for potentially untrusted input. Validate required meter attributes before converting them to integers. |

## Tool cross-reference

- Pylint identifies bug risks, maintainability warnings, and conventions. The mutable-default finding matches [W0102: dangerous default value](https://pylint.readthedocs.io/en/latest/user_guide/messages/warning/dangerous-default-value.html). The other Pylint rule IDs above are copied from the saved report.
- Flake8 identifies the four formatting violations above. Its [error-code guide](https://flake8.pycqa.org/en/latest/user/error-codes.html) explains that E/W style codes come from pycodestyle.
- Bandit's [B605 shell-process rule](https://bandit.readthedocs.io/en/1.9.4/plugins/b605_start_process_with_a_shell.html) corresponds to the concatenated shell command at line 63. The saved report supplies its High severity and High confidence ratings.
- Bandit's XML rules distinguish the [B405 import warning](https://bandit.readthedocs.io/en/1.9.4/blacklists/blacklist_imports.html#b405-import-xml-etree) from the [B314 parsing-call warning](https://bandit.readthedocs.io/en/1.9.4/blacklists/blacklist_calls.html#b313-b320-xml-bad-elementtree). Both concern handling untrusted XML and recommend hardened parsing.
- Bandit's [B105 hardcoded-password rule](https://bandit.readthedocs.io/en/1.9.4/plugins/b105_hardcoded_password_string.html) reports a possible secret based on the string assignment; usage context still needs review, as noted in the table.

This document records findings and proposed fixes. No source-code fixes have been applied as part of this review.
